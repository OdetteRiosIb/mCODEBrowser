Introduction

The Minimal Common Oncology Data Elements (mCODE) is an initiative designed to increase data interoperability by assembling a core set of structured data elements for oncology electronic health records (EHRs). While mCODE provides a solid foundation for standardizing clinical cancer data, it has notable limitations: it does not establish relationships between elements, and it lacks medical image or radiomics elements. To address these gaps, a specialized ontology was developed based on mCODE to introduce semantic relationships. Additionally, this ontology features an embedded ontological extension for Radiotherapy, Radiomics, and Dosiomics.
